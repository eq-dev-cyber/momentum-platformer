# Momentum Platformer

Momentum Platformer is a 2D precision platforming game built using Godot 4.

## About the Game

The objective is to reach the end of a challenging obstacle course by jumping between extremely narrow platforms.

Unlike traditional platformers, movement is acceleration-based. Players must manage their horizontal momentum, carefully time their jumps, and account for platforms at different heights.

The game features:
- Acceleration-based horizontal movement and friction
- Gravity-based jumping mechanics
- 30 procedurally generated platforms with varying heights and distances
- A timer to track completion time
- Automatic restarting when the player falls

## Controls

- **A / D or Left / Right arrows:** Move
- **Space:** Jump
- **R:** Restart after completing the level

## How to Play

**Play online:** [Momentum Platformer on itch.io](https://developer0112358.itch.io/momentum-platformer)

Alternatively, to run the game locally:

1. Download or clone this GitHub repository.
2. Install Godot 4.
3. Open Godot and import the `project.godot` file.
4. Open the project and press **F5** to run the game.

## Technologies Used

- Godot 4
- GDScript

## Goal

Reach the final platform as quickly as possible without falling!
